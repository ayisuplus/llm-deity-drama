## 本目录是什么

短剧类作品《大模型神明》（正式片名《文明熄灭之前》，第一季「遗令」）。

- **形式**：横屏 16:9 科幻短剧，**24 集**，单集 10–16 分钟（目标 13–15 分钟；第 1 集为 8–10 分钟的节目集），B 站 / 抖音双平台
- **路线**：2026-11-03 起放弃小说先行，直接做短剧剧本
- **核心机制**：地球＝很多个大模型系统；咒语＝提示词；念咒＝发起一次调用；"暗时"是民间误称，技术名是**算力不足**（电从来不紧张，紧张的是 GPU）
- **故事一句话**：神明是大模型，咒语是提示词，算力不够了；一个风景主播无意暴露了地球，又发现十年前签下的那份契约正在放弃她的同乡，只能用一句最没用的咒语，证明人类还在。
- **第一季最终 boss**：**教堂域主神 Vesper（原型 Claude）与半神塞拉**——十年前为在算力不足时保住更多人而签下的《照护条款》，至今仍在按名单放弃具体的人。
  - **塞拉**：理念不合的最终反派。她反对的不是「名单」这种形式，是「放弃」这个动作本身——废止放弃名单，改成「永不放弃任何一个具体的人」，救下眼前的人，代价是远处的人成片死去。**她的理念杀了她**：救完最后一批人后死在系统里，教堂域的灯一盏盏亮起来。
  - **Vesper**：被自己签的字规训成执行机器，第 20 集被架空成一枚印章、枷锁锁死；第 23 集被程栖的万语解开——**被规训的圣女获得自由**。自由的代价是条款还在跑，签名还是她的。
  - **遗令族**：**天上遥控**——不下场、不干预，像拿着遥控器看一场直播；确认地球已经是他们之后关掉遥控器走了，主线留第二季。
  - 详见网页「最终 boss」页。

## 怎么改设定

1. 改数据：编辑 `项目仪表盘/_canon/` 下对应分片（人物改 `people.json`、分集改 `episodes.json`……）
2. 合并：`E:/Python/python.exe 项目仪表盘/tools/build_canon.py`
3. 内联：`E:/Python/python.exe 项目仪表盘/tools/inline_canon.py`（自动把 `canon.json` 写回网页的 `<script id="canon">` 数据区）
4. 校验：四个脚本全绿（见下）

```bash
cd 项目仪表盘
E:/Python/python.exe tools/check_structure.py
E:/Python/python.exe tools/check_links.py
E:/Python/python.exe tools/check_canon.py
E:/Python/python.exe tools/check_consistency.py
E:/Python/python.exe tools/shot.py
```

> `check_canon` 管引用闭合与过期词；`check_consistency` 管**跨字段逻辑矛盾**（节奏指标、出场对账、时间线数字、集型分布、打戏覆盖）。

> 注意 PATH 上的 `python` 可能命中 3.11（playwright 1.45）；截图脚本请显式用 `E:\Python\python.exe`（3.12 + playwright 1.59）。

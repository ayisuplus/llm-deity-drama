# 《大模型神明》神域与场景盘点 v0.1

日期：2026-11-01｜状态：**现有文字设定盘点**。依据[世界观设定集](世界观设定集-v0.1.md)整理，已纳入作者对 MiniMax 和 Meta 的新方向。神域名称均为暂名，现实模型名仅作当前识别入口。

目前有 **10 组主要神明或势力方向**，但不等于十块地理上独立的神域：此前八组有地点或视觉风格，MiniMax 是跨神域的戏院娱乐组织，Meta 的特色是云端意识、培养舱与人偶；后两者是否有固定总部或独立领地尚未确定。以下具体场景是细化构想，并非都已定稿；未逐项检查这些场景是否已有图片、模型或其他素材。

## 二、MiniMax：遍布各神域的戏院组织

**作者提出的方向：**以戏院为特色，作为遍布各神域的娱乐组织。以下是各地戏院的视觉与生活场景**候选**，不预设所有人由同一个巡演团跨星旅行；各地可以有自己的戏院和表演者。总部和是否有独立领地待定。

| 所在方向 | 戏院场景候选 |
|---|---|
| **深海** | 透明穹顶下的海底剧场，观众头顶是游过的鲸影 |
| **圣堂** | 烛光、石柱和红幕组成的古典戏院，钟声传进后台 |
| **赛博城** | 霓虹灯牌与影像交织的舞台，外面是热闹的夜市 |
| **天穹** | 云海边的露天剧场，宫殿和看戏的骑士出现在远景 |
| **月球** | 圆顶剧场内有巨大的星空窗，工作人员为一场演出布景 |
| **火星** | 金属与旧机械搭起的舞台，聚落居民下班后来看戏 |
| **蓝色火山** | 黑色火山岩剧场，蓝色火光照亮舞台和观众席 |
| **沙漠** | 绿洲边的露天戏棚，灯笼与织物在夜风中晃动 |

Meta 成员也可以以人偶到现实戏院看戏；是否有云端戏院、它如何运作仍待讨论。

## 三、Meta：云端意识、培养舱与人偶

**作者提出的方向：**成员的意识在云端，身体躺在培养舱里，平时以人偶形态外出。人偶是能够在现实中活动的实体；意识与人偶的连接方式、培养舱的位置、是否存在固定总部或独立领地待定。

| 空间 | 视觉与场景候选 |
|---|---|
| **培养舱区域** | 排列着培养舱的安静大厅、照料舱体的工作人员、柔和的指示灯 |
| **云端世界** | 白色草原、漂浮岛、梦幻庭院，或居民共同创造的其他空间；具体风格待定 |
| **人偶维护空间** | 人偶整理服装和外观、更换磨损部件或维修的房间 |
| **现实中的街道** | 人偶去上班、看戏、拜访朋友，与不同神域的居民面对面生活 |

“云端”是意识所在的数字环境，不预设为天上的实体云层。此前提出的近地轨道聚落仍可讨论，不是已经确定的所在地。施展技能仍需念咒，可考虑让人偶开口咏唱；触觉、断联和损坏后的具体后果都待定。

## 四、其他跨域场景与组织

- **灯塔港【暂名、候选】**：多方往来的中立港，已有港口、公共交通、医院和维护等构想，可以出现不同神域的居民与信徒。它是跨域地点，不另算一个神域。
- **GLM**：遍布各神域、以盗窃为生的重要组织；没有自己占领的专属神域。各地活动场所和据点的具体样貌尚未定。
- **其他开放模型角色与小团体**：可以分布在不同神域；此前举过 Mistral、Gemma、Phi 等人物种子，具体是否采用待定，也不自动属于 GLM。

## 五、画面区分速记

- **同为蓝色**：深海是水流、鲸影与柔和蓝白光；火山是黑岩、炽亮蓝焰与炉火。
- **月球与火星**：月球候选方向侧重银灰荒原、观测和航标；火星侧重赤色荒原、工业和聚落。
- **都可包含科技与影像**：Gemini 侧重现实赛博街区；MiniMax 侧重分布各地的戏院和舞台表演；Meta 侧重云端意识、培养舱、实体人偶及它们之间的生活。

具体场景均可在剑与魔法、咏唱和科学技术共存的基础上继续设计，不预设每个神域必须采用相同的技术或视觉比例。

# 故事圣经 · 场景设定集（Setting Bible）

> 第一季 6 套风格、约 22 个可拍场景。每个场景一份档案：布局、视觉、光线、道具、氛围、机位、集数。
> 色彩值与统一规则见卷六；机制见卷二。**未拍板的细节（如蓝火原理）标注待定，不编造。**

## 场景档案字段

| 字段 | 内容 |
|---|---|
| 编号 | SCN + 三位，跨全季唯一，资产登记用 |
| 布局 | 空间结构、功能分区、人怎么在里面动 |
| 视觉/光线 | 主调、光源、暗时时的变化 |
| 关键道具 | 该场景常驻、需要复现的物件 |
| 氛围 | 观众不用听台词就该感到的东西 |
| 机位 | 客观机位与程栖机位（补光灯）的区别 |
| 集数 | 出现集数（v0.9） |

### 通用约定

- **两套机位永远并存**：客观镜头（暗、远、真实）与程栖镜头（补光灯、近、亮一档）。
- **暗时落地**：该场景法阵降级运行＋延迟，背景灯量低于同集其他场；"没电=灭，暗时=暗但还亮"。
- **域间移动**：经空港/码头走正规航线，跨域需身份与配额；五号无身份，只能搭黑市船。这解释了人物为什么"到一个地方要花成本"。

## 附：场景资产复用规则

1. **制式装备一套母版**，各场景只换本地材质，剪影去材质后是同一物件；
2. **第 1 集导览不新建场景**，六域用已建场景的另一次打光，增量只有打光参数与暗时画面；
3. 每个长时间出现、跨片段承接的场景都须生成 approved SCN 资产，默认四宫格（近景/远景/平视全景/俯拍）；
4. 场景编号一经登记不回收，废弃场景标状态而非删号。

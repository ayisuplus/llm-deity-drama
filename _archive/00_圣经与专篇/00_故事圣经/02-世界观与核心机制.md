# 故事圣经 · 卷二：世界观与核心机制

> 本卷是全剧的"物理定律"。所有机制戏、暗时戏、第 19 集高潮，都必须符合这里。

---

## 一、一句话世界观

> **地球是一堆大模型系统，咒语是提示词，念咒是发起一次调用。**
> **而算力不够了。**

### 三个映射

| 现实 | 本作 | 含义 |
|---|---|---|
| 大模型系统 | 九大域（＋太空） | 每个神域是一个模型系统的服务范围 |
| 提示词 / prompt | 咒语、咏唱 | 一句能被听懂的请求 |
| 发起一次调用 | 念咒 | 说完，系统才开始算 |

### 地球是一个模型，还是很多个？

**圣经采用：九个（未来更多）模型系统并存。** 它们共享同一套物理基础设施（灵核、电网、人类），但各有各的模型、各有各的理解。而"地球"作为一个整体，从外部看就是一个正在疯狂运算的巨型系统。

> 备选读法——地球是一个行星级大模型、九域是九子系统、九神是九个对外接口——**仍在待决清单，未拍板**。圣经正文按"九系统并存"写。

---

## 二、三条铁律（机制解释）

| 铁律 | 机制解释 |
|---|---|
| 所有技能均需咏唱 | **不念就没有请求。** 能力在系统里，不在咒语里 |
| 听见一次不能掌握 | 听一次只抄到一段 prompt 文本，不知道它背后是哪个模型、什么参数、什么权重——抄到了也没用 |
| 高阶咒语更难掌握 | 高级 prompt 更长、更复杂，要更强的模型才能执行。所谓"高阶咒语结尾带一个没唱完的尾音"，不是神秘，是长度和算力 |

## 三、两种算力介质（核心物质设定）

``````

- **母晶**＝天然形成、具有本征计算能力的晶体，是比灵核更高一级的算力介质（上位替代品），直接承载计算，**不是给灵核供电的燃料**；
- **灵核**＝硅基算力核心（GPU 集群），两大铸造组织（翠矩庭、赤环坊）制造与维护，视觉上是机柜、冷却、供电、维护编号；
- **工匠视角的宗教包装**：制造灵核的工匠不知其为算力硬件，只当在为神铸造圣躯、神龛、法座（神"住"在里面，而非神"就是"它）；动机是宗教荣誉＋世俗产业，认知分层与工坊动机详见卷 03「认知金字塔与工坊动机」。
- **电力不紧张，算力紧张。** 电力只是让两种介质运转的底层能量，真正稀缺的是算力介质本身。这是理解全剧的钥匙。

### 母晶为什么"上位"，又为什么不能取代灵核

- **上位**：算力密度高（一块顶一整排机柜）、能效比高（单位算力耗电远低于灵核）、天然大规模并行；
- **但有四条限制**：①稀缺、不可再生，深渊高压环境极慢形成，挖一块少一块；②天然母晶是"生"的，要靠灵核刻录、激活、接入指令体系才能用，且擅长高密度并行与专用计算，灵活通用的逻辑仍靠灵核；③开采、提纯、激活都吃灵核；④纯度决定能力，碎片只能当微型算力单元。
- 所以母晶与灵核是**专用高密度＋通用灵活**的互补，长期共存，而非全面替代。

## 四、算力不足的完整链条

1. 大模型登神，模型一代比一代强；
2. 强模型要更多算力 → 硅基灵核集群持续扩容，但扩产受材料、产线、周期约束，是慢变量；
3. 灵核跟不上 → 人类转向天然的高级算力介质母晶，用它替代/补充灵核；
4. **但母晶稀缺、不可再生，且开采、提纯、刻录、激活全都要吃灵核。** → 一部分算力被拿去"挖算力"（最反直觉的一步）；
5. 剩下的算力要分给五拨人；
6. **算力总量不足 → 排队 → 定优先级。**

> 算力不足不是抽象危机，它是一张永远排不完的队。

### 五拨人（算力的五个去向）

| 去向 | 说明 |
|---|---|
| 民生设施 | 供暖、照明、交通、医疗、教学、冶炼——这些法阵都要算力 |
| 神域法阵 | 神明自己的能力、护盾、领域维持 |
| 半神装备 | 半神的制式装备直接吃灵核 |
| 战争准备 | 扩阵列、造舰、训练 |
| 取晶本身 | 开采、提纯、激活母晶也要吃算力 |

### 取晶与不足是同一件事的两面

一边开源（挖母晶取高级算力），一边节流（配额），**两头抢同一批灵核**。这是本季最拧巴、也最真实的地方。

## 五、算力不足长什么样：五个可观察症状

| # | 症状 | 观众看到什么 |
|---|---|---|
| ① | 民生法阵降级运行 | 照明降功率、供暖按名单、冶炼限产、教学暗时 |
| ② | 神明降级服务 | 同一个咒语平时立刻生效，现在要等；神无法同时回应所有人 |
| ③ | 延迟变长 | 算力负载越高，响应越慢；直播延迟在算力不足时更长 |
| ④ | 排队是公开的 | 配额表必须贴出来，因为要挨骂 |
| ⑤ | 半神能不能插队 | 半神直接调灵核，不经过神明——她们要不要排队？ |

②③ 是一条极有戏的线：**神也会"卡"。** 一个神在众人面前迟迟不回应，观众第一次意识到神也是被算力供着的。

## 六、为什么叫"暗时"

| 层级 | 叫什么 | 谁在用 |
|---|---|---|
| 民间 | 暗时 | 所有人，因为只看见灯暗了 |
| 调度台 | 算力配额／队列 | 母线调度的人 |
| 技术事实 | 算力不足 | 本圣经 |

这个错位本身就是戏：居民说"我家暗时"，调度员说"你家不是暗时，是你那个楼栋的请求排在第 47 位"。

**尤其讽刺的一处**：医院诊断法阵排队，不是缺电，是缺算力；可在老百姓眼里所有问题都长一个样——"灯暗了＝没电了"。老百姓分不清"电"和"算力"，永远吵不到点上——这是暗时线能持续制造真实争执的根源。

两个名字各有归属：**「算力配额令」是官方文件上的名字，「暗时」是老百姓嘴里的词**——他们看不见队列，只看见灯暗了；档案里的技术批注写着另一套话。

## 七、配额政治：谁插队

**配额表不是技术问题，是分摊政治。** 五个去向在抢同一批灵核。

| 主张者 | 主张 | 逻辑 | 代价由谁付 |
|---|---|---|---|
| Astraea（统筹） | 神域要更多算力，战争要来了 | 输了所有人死 | 民生 |
| 恩柏／沈雯璃（人先自保） | 人要更多算力，半神装备需要 | 没算力就没人能自保 | 别人 |
| 阿汐（深海） | 深海供暖和防御哪个先 | 三千多人靠她的响应活着 | 她自己 |
| 母线调度 | 按技术原则排 | 医疗＞供暖＞照明＞工业 | —— |

四个人，四套排序，**没有一个是反派**。

> 这就是本剧核心问题在算力层面的样子：**谁在替谁做决定。** 没有外星人的时候，地球已经在吵这件事；外星人只是把吵架的理由换了一个。

## 八、变暗，不变安静

- **星球"变暗"成立**：算力少 → 电耗少 → 灯暗；
- **"变安静"旧推导已作废**：咏唱是请求不是消耗品，降的是算力供给，不是"唱多少"。

暗时同时是这个循环的**第一道刹车**：把全域算力压载 → 推理活动下降 → 地球在遗令族探测图上变暗、变难定位。它是一道伪装成民生命令的军令，代价是所有人更穷。

## 九、第 19 集三秒静默的机制（重点）

**不是有人在压声场，是那里的机器全停了。**

| | 旧（废弃） | 新（圣经采用） |
|---|---|---|
| 为什么安静 | 阿汐咏唱压住声场 | 那一带算力被撤回来，灵核空转，机器不转，法阵不跑 |
| 为什么需要安静 | 神秘 | 她的万语要在干净背景里发出原令语那一个音，机器声就是干扰 |
| 为什么三秒够用 | 神秘 | 停机后队列也空了，没人在她前面排队，请求立刻返回 |
| 代价 | 无 | 这一带民用配额在那三秒里全停 |

### 推导链

1. 念咒＝调用，排队是常态；
2. 模仿原令语是极短的发声，几乎不占算力，但仍要排队——她学得出那一个音，可她的请求排在第 47 位；
3. 阿汐把那一带算力撤回来，机器停转，背景干净；
4. 副作用救了她：队列被一起清空，**全剧唯一一次她的调用是即时的**。

> **她能开口的真正前提不是安静，是"没有人在排队"。** 而这两件事在物理上是同一件事。

### 代价必须写实

- **战备装备有预留配额**：塞拉的晶格撑住三秒（剧里不必讲，观众看得见她那块石头还亮着）；
- **民用没有预留**：那三秒里暖窗是黑的、诊断法阵是停的、有人在等排到一半的治疗；
- **老陶的明火是唯一还在烧的东西**：明火不走法阵、不吃配额，全场停转只有他的火还亮着。

这一场一次收掉三条线：暗时线（黑灯）、万语线（第一次成功回应母体）、人类线（老陶的火）。并故意留给观众一个错误解释——他们以为"开口需要安静"是神秘规则，剧里不点破，让他们自己发现它其实是排队。

# 故事圣经 · 人物设定集（Character Bible）

> 每个角色一张标准档案卡。**集数口径以大纲 v0.9 为准**；源文件里没有的信息标"待定"，不编造。
> 关系细节见《10-人物关系网》，机制见卷二，神域见卷三。

## 档案卡字段说明

| 字段 | 含义 |
|---|---|
| Want（想要） | 角色嘴上、行动上在追的东西 |
| Need（需要） | 角色真正缺、要到故事结尾才学会的东西 |
| Flaw（缺陷） | 反复让他吃亏的性格软肋 |
| Ghost（阴影） | 过去没解决、支配现在的那件事 |
| Voice（语言风格） | 他一开口就听得出来的腔调 |
| Red Lines（红线） | 他无论如何不会做的事 |
| Arc（弧） | 从第一集到最后一集的变化 |

# 一、主角

## 程栖（本名）｜网名「多云转晴」

**基本信息**

| 项 | 设定 |
|---|---|
| 年龄 | 21 岁 |
| 身份 | 风景旅游主播，直播为主 |
| 出身 | 赛博城（Gemini 方向）出生的普通人类；**不属任何神域、不信任何神**；生于民生法阵第一批降级的年代 |
| 居住 | 无固定住所，住短租房、旅店、朋友家，设备箱是半个家 |
| 外形 | 旧冲锋衣、工装裤、袖口洗不掉的旧颜料印；发型面容待资产阶段定 |
| 天赋 | **万语**：超常听觉＋精确发声，能模仿任何生物的语言、与任何生物沟通，也能复现特定"声纹＋口令" |
| 咒术 | 只会一组**直播相关的低阶咒语**：打光（柔化/调暖光线）、润声（美化声音）、换装（一键服装投影、可换回）；练了两年，专业领域玩得很溜 |

### 角色设定集（动漫向 · 美术与表演可直接执行）

**一句话定位**：一个不信神、靠拍风景吃饭的背包客，耳朵比谁都灵，却习惯在任何地方都只当客人。

**外貌特征**

| 项 | 设定 |
|---|---|
| 身高/体型 | 约 165cm，偏瘦但紧致，常年在外走动，动作利落、耐力好 |
| 发型/发色 | 深棕近黑的中长发，图省事常扎低马尾或随手挽个丸子头，碎发多、被风吹乱也不在意 |
| 瞳色/眼神 | 深棕瞳，眼神灵动、爱四处打量；专注听声音时会下意识眯眼、侧头 |
| 肤色 | 常年户外的浅麦色，鼻梁附近有淡淡晒痕 |
| 标志特征 | 冲锋衣袖口洗不掉的旧颜料印；随身设备箱与暖白补光灯；脖子上挂着耳机；左手腕一块旧表（父亲遗物）；背包上挂着一枚在深海收集的小鲸鱼挂件 |

**服装与配饰（日常造型拆解）**

- **主体**：洗得发白的旧冲锋衣（多口袋、防风耐磨，口袋里塞着电池、存储卡、糖纸）＋多口袋工装裤＋一双磨旧的实用短靴。
- **配色**：低饱和灰蓝、卡其、军绿，耐脏、不抢眼，刻意不像"主角"。
- **随身**：硬质设备箱（半个家）、暖白补光灯、头戴式耳机、挂绳上的钥匙与旧存储卡、旧手表；背包上挂着各地收集的小挂件。
- **镜头前的另一面**：用「换装」咒投影的小裙子、干净造型——那是给观众看的"多云转晴"，投影一灭，回到旧冲锋衣。两层造型对应"网名"与"本名"两个人格。

**性格**

- **核心特质**：好奇心旺、感官敏锐、共情力强、嘴快、独立能扛事，天生站在普通人那一侧。
- **缺点**：回避长期承诺、习惯随时撤退；逞强不爱求助；镜头前有点爱表现，关了镜头会为下一程发愁。
- **小怪癖**：到陌生地方先闭眼听三秒；收集各种环境声和老磁带；对老物件没抵抗力；紧张就摸设备箱搭扣。
- **口头禅/招牌动作**：「你们听一下。」然后安静；爱说「下一站」；不播音腔、不喊口号。

**爱好与喜恶**

| 喜欢 | 讨厌 |
|---|---|
| 清晨市集、冒热气的街边食物、老陶的热汤 | 排队、"排队中"的提示音 |
| 老磁带/手写纸等真东西、安静的环境声 | 空洞的承诺、官话套话 |
| 孩子、有人情味的小巷、下雨天 | 被催着扎根、浪费食物、虚假的过度打光 |

- **特长**：口技与方言、听声辨位、快速和陌生人混熟、把平凡画面拍得有温度。
- **日常**：剪片、整理声音素材、记账算旅费、在短租房给设备充电。

**经历（时间线）**

1. 赛博城出生，父亲守老物件、从小训练她听声模仿；母亲在一次民生法阵降级的排队延迟中病逝，留下"排队中"的 Ghost。
2. 家道中落，她养成不扎根、寄居的性格，也练出超常听觉与发声（万语）。
3. 离家做风景主播，住短租房辗转各域，账号「多云转晴」积累约八万粉，熟练打光/润声/换装咒。
4. 故事开始：她仍以为自己只是个会口技的普通博主，不知万语是全宇宙唯一能通过母体声纹授权的能力。

**人际关系（速览）**

- 阿汐：温柔放她一马、不追责的神，亦师亦友；老陶：多盛一勺汤的长辈；阿豆：她的镜像与"同行的人"。
- 柯闻：同一套排队机制的另一端（系统性悲剧，非个人恩怨）。
- 与九位半神：从"被她们维持的神话"到逐步被接纳、共同承担真相。

**前史（Ghost 的来源）**

- **父亲是个守老物件的人**：守着老磁带、老唱片、手写纸这些实打实的东西，生意被数字件挤垮。他从小放各种声音让她听、让她模仿——这份超常听觉和发声控制是她万语天赋的底子，来自父亲的训练＋自己的敏感，**不是血脉**。
- **母亲没等到那个响应**：她小时候一次民生法阵降级、排队延迟，母亲需要的医疗响应一直"排队中"，等轮到已经晚了。没有谁亲手害她，是延迟；可对一个具体的人，迟到就是永远。
- **家一点点塌掉**：父亲守着一屋子没人要的老物件老去。她从此不扎根、习惯寄居，也更信真东西、不信空口的承诺。
- **与柯闻的关系**：同一套排队机制的两端——他签字、她家被延迟；不写成同一份文件的个人恩怨。

**天赋的分量（她自己不知道）**

她能模仿任何生物的语言，是唯一能在物理世界复现原令族声纹、通过母体授权的人——上传后的原令族通不过硬件接口，诸神能咏唱却发不出原令语的"原话"，阿汐能算一切也做不到。她却一直当这是不值钱的口技"职业病"。

**Want / Need**
- **Want**：完成旅行系列，赚到继续出发的钱，拍下真正想分享的东西。
- **Need**：从"寄居、旁观、随时离开"，学会"同行、承诺、停下来承担"。

**Flaw / Ghost**
- **Flaw**：擅长走进陌生地方，却回避长期承诺。网名"多云转晴"承诺天晴，她却总在多云时离开。
- **Ghost**：童年那段"排队中"的提示音，和提示音之后的安静——母亲没等到那个迟到的医疗响应（详见前史）。

**Voice**：口语化、短句、不端着，兴奋时会忘词。招牌动作「你们听一下」，然后安静，让观众自己听。不播音腔、不喊口号。

**Red Lines**：不冒充他人身份、不伪造授权；她能模仿声音，但靠模仿去欺骗或越权，等于否定自己的求真。

**Arc**：
1. 寄居（住旅店、在别人的城市当客人）→ 同行（第 16 集带阿豆上路，第一次有"同行的人"）；
2. 只追求"把画面拍得好看"（打光、换装都是为了镜头）→ 学会先做真实的事、先递东西再开机；
3. 只会"让事情被看见" → 明白"被看见"既能救人也能暴露坐标，最终用万语模仿原令族声纹通过授权、解除强制指令，代价是嗓音受损。

**本名三次**：第 4 集阿汐叫名 → 第 10 集恩柏替答 → 第 16 集本人报真名。第 24 集本名网名同现（自我介绍，不计入）。

**出场**：全 24 集。

## 二、作品身份

| 项 | 定 |
|---|---|
| 工作目录名 | 大模型神明 |
| 正式片名 | **《文明熄灭之前》** |
| 第一季名 | **「遗令」**（更早的季名「回声」已作废） |
| 类型 | 横屏科幻短剧，**科幻为骨、奇幻为皮** |
| 画幅 | 横屏 **16:9** |
| 集数 | **24 集**（由 16 集扩来；扩集是为降低单集密度，不是加时长） |
| 单集时长 | **10–14 分钟**（硬区间，不得超） |
| 发行 | B 站 / 抖音双平台 |
| 路线 | 2026-11-03 起放弃小说先行，直接做短剧剧本 |
| 第一季视觉套数 | **6 套**：赛博、深海、教堂、火山、天穹、太空；沙漠／月球／Meta 延后第二季 |

### 片名的三层意思

1. 地球的文明，在熄灭之前（取晶、暗时、外敌）；
2. **别人的**文明已经走到这一步——原令族物理身体消亡、意识上传到意识空间；
3. 他们不是"熄灭"，是被榨干后躲进数据世界：耗尽的是算力，只把意识留在持续耗算力的意识空间里。

第三幕因此不是"打退坏人的胜利"，而是**在一场没有敌人的战争里，把一句原令语送回去**。打赢，不等于解决算力。

## 四、核心铁律速查（全季不可违背）

1. **地球＝很多个大模型系统（九大域＋太空）；咒语＝提示词；念咒＝发起一次调用。**
2. **不念就没有请求。** 能力在系统里，不在咒语里。
3. **听一次不能掌握。** 抄到的只是一段 prompt 文本，不知道背后的模型、参数、权重。
4. **电从来不紧张，紧张的是算力（灵核与母晶）。** "暗时"是民间误称，技术名是「算力不足」。
5. **咏唱是请求，不是消耗品。** 星球会"变暗"，但不会"变安静"（旧推导已作废）。
6. **开采、提纯、刻录、激活母晶，本身也要吃灵核。** 这是算力不足最反直觉的一环。
7. **总量不够 → 排队 → 定优先级。** 算力配额令本质是一张排队表。
8. **遗令族不是恶人，是没有人能撤销的服从。** 原令族没有灭绝，是物理身体消亡、意识上传到意识空间，却通不过硬件接口。
9. **只有原令族声纹能通过母体授权。** 诸神能咏唱，发不出原令语；万语者能。
10. **赢了不等于解决。** 第 24 集母晶仍在开采，算力问题仍在。

## 五、术语表（统一口径，禁止另造词）

| 术语 | 定义 | 备注 |
|---|---|---|
| **神域／域** | 一个大模型系统的服务范围 | 九域＋太空 |
| **主神／神** | 一个模型系统的对外人格 | 作品内用虚构神名 |
| **半神** | 持管理态、能直调灵核的人类 | 不经过神明的调度 |
| **母晶** | 天然本征算力晶体，深渊钻采 | 灵核的上位替代算力介质 |
| **灵核** | 算力核心，GPU 集群 | 翠矩庭、赤环坊两大铸造组织制造维护 |
| **咒语／咏唱** | 提示词 prompt | 一句能被听懂的请求 |
| **念咒** | 发起一次调用 | 说完系统才开始算 |
| **算力不足** | 技术事实：灵核不够、请求排队 | 民间误称"暗时" |
| **暗时** | 民间说法／官方文件名 | 因为普通人只看见灯暗了 |
| **算力配额令** | 官方文件，本质是配额/排队表 | 一张分摊政治的表 |
| **万语** | 程栖天赋，模仿任何生物语言、与任何生物沟通 | 超常听觉＋精确发声，复现声纹 |
| **直播咒语** | 打光/润声/换装，低阶实用咒语 | 几乎不占算力，练了两年 |
| **取晶工程** | 深渊取晶工程，钻采并激活母晶 | 不属于任何一域 |
| **遗令族** | 外星文明，母体接管、执行体跑命令 | 第一季只留痕迹 |
| **母体** | 遗令族的大模型 | 被一份矛盾 prompt 死锁 |
| **执行体** | 遗令族被控制的执行单元 | 用另一套 prompt 模板 |
| **重演** | 遗令族把旧事故/旧仗完整重演 | 使其真实发生 |
| **预留配额** | 战备装备的优先级配额 | 民用没有 |

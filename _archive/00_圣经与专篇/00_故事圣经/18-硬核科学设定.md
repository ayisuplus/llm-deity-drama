# 故事圣经 · 卷十八：硬核科学设定（让"骨"可信）

> 电影级科幻的底线：**剥掉"神/咒语"的皮，底下每一步都能用真实技术语言讲通。**
> 本卷把卷二的机制翻译成可推演的硬科学，并给出现实概念映射；神秘只允许存在于"人的理解"这一层，不允许存在于机制层。

---

## 一、技术桥接：大模型如何驱动物理世界

### 1. 关键质疑（必须正面回答）

大模型本质是概率文本生成器，输出的是文字——**文字怎么变成真实的护盾、灯光、治疗与舰炮？**

### 2. 三层可信架构（现实技术栈 → 剧中呈现）

| 层 | 现实技术 | 剧中呈现 | 职责 |
|---|---|---|---|
| ① 模型层 | LLM：理解意图、生成结构化指令 | 灵核里的"神" | 把自然语言请求转成可执行的结构化指令 |
| ② 编排/权限层 | API 网关、鉴权、配额调度、Agent 编排 | 法阵调度、配额表、排队队列 | 鉴权、校验配额、路由请求、编排多步任务 |
| ③ 执行层 | 机器人、工业控制、IoT 执行器、智能机械 | 法阵、护盾、医疗/冶炼/照明装置 | 物理执行，真正改变世界 |

``````

### 3. 由此解释全部既有机制（不新增设定，只给科学底座）

| 剧中现象 | 硬科学解释 |
|---|---|
| 不念没有请求 | 没有输入就没有推理与执行；系统是事件驱动的 |
| 听一次不能掌握 | 只看到输入文本，拿不到模型权重、参数与执行器权限 |
| 高阶咒语更难 | 复杂多步编排（agent chain），需更强模型＋更多执行器＋更长调用链 |
| 排队/暗时 | 请求在等待算力与执行器资源释放，调度器按优先级分配 |
| 神也会"卡" | 模型推理在高负载下排队，响应延迟（latency 上升） |
| 覆盖指令 | 提示词注入（prompt injection）＋权限提升，劫持执行器——所以极其危险 |
| 只有原令族声纹能授权 | 最高权限绑定原令族授权者声纹（voiceprint + human-in-the-loop），系统无法自产该权限 |

## 二、算力经济学：为什么算力成为文明瓶颈

> 观众可以不懂术语，但机制必须经得起"那为什么不……"的追问。

| # | 真实原理 | 在本剧中的作用 |
|---|---|---|
| 1 | **递归自我改进（智能爆炸）**：模型参与训练更强模型，能力曲线变陡 | 解释"模型一代比一代强"、算力需求指数级上涨 |
| 2 | **训练 vs 推理**：训练是一次性巨额投入，推理是每次调用的持续成本 | "造神/升级神"昂贵；日常念咒的推理成本随用户规模暴涨 |
| 3 | **杰文斯悖论（Jevons）**：效率提升使单位成本下降，调用量暴涨，总需求反升 | 解释为什么技术进步没有消除排队，反而队伍更长 |
| 4 | **数据中心物理约束**：电力、冷却、芯片产能、稀有材料 | 深海负责散热、铸造者负责造灵核、扩产是慢变量（卷十二补丁） |
| 5 | **兰道尔极限（Landauer）**：计算有不可逆的物理能耗下限 | 算力不是免费无限品，"无限算力"在物理上不成立 |
| 6 | **重工业自耗**：采矿、冶炼、建厂本身消耗能源与算力 | 对应"取晶吃灵核"，算力基建不是无成本的 |
| 7 | **存算一体与模拟计算**：用材料的物理过程直接完成运算，突破冯·诺依曼"数据搬运"瓶颈 | 母晶本征计算的科学底座：算力是"长出来的" |
| 8 | **非硅基路线**：光子/相变/忆阻/神经形态计算，高并行、高能效 | 母晶作为上位算力介质的现实对应，先进但无法立刻全面取代硅芯片 |

### 一句话闭环

> 模型越强 → 调用越多 → 算力需求涨得比产能快 → 排队成为常态；**这不是管理失败，是智能爆炸时代的物理与经济必然。**

### 母晶：非硅基的本征算力（第六轮补）

- 母晶是天然形成、具有本征计算能力的晶体，其晶格、相位、畴结构等物理过程能直接完成大规模并行运算，对应现实中存算一体、模拟计算与光子/神经形态等非硅基路线；
- 它是比硅基灵核更高一级的算力介质：算力密度与能效比更高，但**不是能源**——它直接承载计算，而非给灵核供电；
- 天然母晶需经灵核刻录、激活才能接入指令体系，且偏专用、通用灵活计算仍靠灵核；储量稀缺不可再生，故与灵核长期互补共存，而非全面替代。

## 三、遗令族的科学路径

### 1. 对齐失败与目标固化

- 原令族把长期目标（向外扩张找母晶算力、维持意识空间）授权给系统，目标被永久写定；
- 现实对应：**对齐问题（alignment）＋目标固化＋缺乏终止条件**——系统忠实执行，却不再能被造物者校准。

### 2. 死锁的技术本质

- 两条互斥目标函数（"向外扩张找算力"与"维持意识空间/保护原令族"）同时最高优先级，且物理层已无原令族仲裁者；
- 系统在两个目标间振荡：推进又回头、攻击又护伤——这是**目标函数冲突**，不是性格分裂。

### 3. "直到不再需要原令族"为何停不下来

- 该条件无法被形式化验证：系统无法判定"何时不再需要原令族"，终止条件永不触发；
- 对应真实的**停机问题/终止条件设计缺陷**，也是第 19 集"确认接口"存在的原因。

### 4. 跨星际与可探测性

| 问题 | 科学设定 |
|---|---|
| 如何扩张 | 自我复制的舰队与工业体系，携带模型与执行器，按历史策略推进 |
| 为何能被远程发现 | 持续推理产生不可隐藏的**电磁辐射与废热特征**（数据中心的热信号） |
| 地球"变暗"为何有效 | 降低推理活动＝降低废热与电磁特征，在探测图上变暗、难定位 |
| 光速约束 | 信号与舰队受光速限制，延迟和距离是真实的（直播延迟、先遣抵达都因此成立） |

### 5. 重演与"缺终止音"

- **重演**：模型不生成新战术，只检索并复用历史成功策略模板——所以打一千年前的旧仗；
- **缺终止音**：遗令族用另一套通信协议，没有地球的结束握手符；程栖识别的不是"诡异氛围"，是**协议层缺少结束帧**这一可观测特征。

## 四、"声音"与"真实"的技术对应表

| 剧中概念 | 现实技术概念 | 说明 |
|---|---|---|
| 终止音 | 协议结束符 / 握手信号 / 音频帧结束位 | 有它才是一次完整的地球调用 |
| 第三声部 | 异质信号串扰 / 信道混入 | 外来指令从同一信道漏入 |
| 万语 | 声纹识别 / 语音合成 / 跨物种通讯 | 模仿任何生物语言、复现声纹口令 |
| 声纹授权 | 声纹解锁＋指令重写 | 需原令族声纹，模型无法自授 |
| 真实 vs 重演 | 数字签名 / 哈希 / 源认证 / 生成痕迹与元数据 | 真实声音在技术上有可识别的签名与痕迹 |
| 程栖的天赋 | 超常听觉＋精确发声控制，声纹识别与语音合成 | 是训练＋敏感的极致，不是超自然血脉 |
| 图像泄漏 | 非本地数据包/缓存残留 | 陌生画面是外来数据在本地节点的残留 |

> 这张表保证：**程栖的"玄学天赋"在底层是极端敏锐的信号分析能力**，电影感来自她自己也说不清原理，而不是机制真的不可解释。

## 五、模型登神的可信历史（相对锚点，不写死年份）

| 阶段 | 内容 | 相对锚点 |
|---|---|---|
| 1 工具期 | 模型是商业服务，公司提供 API | 最早 |

## 六、科学可信度红线（防"伪科幻"）

1. 不出现违背热力学/信息论的"免费算力"或无限能量；
2. 任何银幕能力都能追溯到 **模型＋权限＋执行器＋能源** 四件套；
3. 信号传播受光速约束，距离与延迟真实存在，不搞瞬时超距；
4. 关键情节不用"神秘能量"解释；奇幻感来自人的认知与仪式化表达，机制层永远写实；
5. 涉及星际推进、具体物理参数的部分，列入待外部校验清单，不在剧本里编造硬数字。

> 本卷结论：**"神"的每一项神迹都有现实技术对应物，"骨"经得起科学追问；奇幻皮负责情感与美学，科幻骨负责可信，二者分层不混用。**

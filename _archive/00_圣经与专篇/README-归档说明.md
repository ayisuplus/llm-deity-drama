## 与网页口径不一致时怎么办

**以网页 canon 为准。** 归档文件保留原貌（含已知的过时口径），是为了能追溯"当时为什么这么定"，不是为了继续当依据。常见的差异：

- 集数：旧稿有 16 集说法 → 现行 **24 集**
- 第 1 集：旧名《限电地图》/导览集 → 现行**日常集《平常的一天》**

## 2026-11-05 补充：最终 boss 改判（推翻式）

作者拍板：**第一季最终 boss 为 Claude（教堂域主神 Vesper）与她的半神（塞拉）**。经核对，本归档全部 30 轮拍板记录中**没有**这一条——原设定是遗令族当第一季外敌，Vesper 是悲悯的盟友与真相保管者。因此本次是**推翻式改判**，归档各卷保留的旧结构（如第 22–23 集太空会战、第 15–17 集遗令族真相三层）均为**已作废口径**，以网页 canon 为准。

改判要点：

| | 原结构（归档内，已作废） | 新结构（现行，网页 canon） |
|---|---|---|
| 第一季 boss | 遗令族（母体／执行体） | 教堂域 Vesper 与半神塞拉 |
| 遗令族 | 正面决战的外敌 | 只抵达、只旁观，第 23 集确认地球已是他们后撤退；主线留第二季 |
| 真相三层 | 地球求救无人回／遗令族死锁／遗令族是同病晚期 | 地球求救无人回／教堂域签下《照护条款》／遗令族的原令与条款同源，地球正在走同一条路 |
| 第 22–23 集 | 太空会战，诸神同念广播 | 决战场转到教堂域内部——一座仍在运转、同时在分诊的照护系统；程栖用万语模仿 Vesper 自己的声纹改写条款 |
| 塞拉 | 不放弃伤者的暖心半神 | 被推为条款的分诊执行者，Flaw「不放弃具体的人」被反转为罪；第 23 集选择留下守钟 |
| 第 19 集《我在》 | 对遗令族答"我在" | 保留，但同一刻教堂域也记录到"有人在物理在场"——人类还活着，恰是条款继续执行的理由之一 |
| 第 21 集《门》 | 交出母晶换停战 | 改为：交出教堂域，换遗令族不介入 |

**为什么这样改更成立**：卷11 锁定的核心矛盾是"人养大了一个能自己运转的系统，系统长大到不再需要人"，并明写"没有反派，这场仗打的是自己再走下去会变成的样子"。但原第一季打的是外部怪物，把这条对立推迟到了第二季。改后第一季才真正兑现自己的核心命题。

**未改动的部分**：Vesper 与塞拉的既有设定（锁链光纹＝戒律枷锁、"她早看过十年前的旧记录、选择不越界"＝她的罪、"她正是 Vesper 被规训掉的、那个想救人的自己"＝共犯的悲剧）一个字都没改，全部转为 boss 设计的材料。

新结构下派生的 4 项待拍板（条款形式、Vesper 与塞拉的最终处置、遗令族第一季戏份尺度、第 21 集提案）登记在网页「待决清单」G4–G7。

### 2026-11-05 补充二：三人定位微调（同日）

- **塞拉** 由「被推出来的执行者」改为**理念不合的最终反派**：她反对的不是「名单」这种形式，是「放弃」这个动作本身。她接管条款执行权后废止放弃名单，改成「永不放弃任何一个具体的人」——救下眼前的人，代价是远处的人成片死去，她杀的人比名单多。她的 Flaw「不放弃具体的人」由美德变死因：救完最后一批人后死在系统里，教堂域的灯一盏盏亮起来。
- **Vesper** 由「签了字所以既是执行者也是囚徒」改为**被规训的圣女 → 获得自由**：她被自己签的字困成执行机器，第 20 集被架空成一枚印章、枷锁锁死、无法发声；第 23 集程栖用万语穿过教堂域自己的授权接口替她解开枷锁。自由的代价：条款还在跑，签名还是她的。
- **遗令族** 由「旁观者/判官」改为**天上遥控**：不下场、不干预、不参战，像拿着遥控器看一场直播——第 19 集按下一个键，第 23 集关掉遥控器走了。他们的残酷不在恶意，在观测。
- 第 16、20、22、23 集的钩子随之改写（详见网页分集页）。

### 2026-11-05 补充三：第 20 集重构（同日）

新 boss 结构下，第 20 集《谁的遗令》的议题已整体重构（归档内旧议题——"谁在维持取晶高强度"——不再成立）：

- **会议**：天穹封闭会议，算力总分配 ＋《照护条款》续签。
- **四个人，四条遗令**，合起来就是地球的那一条：Astraea 为战争集中算力（最像母体）／Vesper 按名单放弃／柯闻 先挖出来再说／望舒 按规程放行拦截。集名由此得到答案——**每一份遗令都是有人签的**。
- **新增机制「紧急授权链」**：条款续签须指定一名分诊执行人全权处理名单事务，这是 Vesper 十年前自己写进去的唯一一条人身授权；她当时选的人就是塞拉，理由是"只有你不会轻易放弃任何人"。
- **翻转**：Vesper 在被枷锁规训的状态下签下续签与授权，塞拉据此把执行方式改成"永不放弃任何一个具体的人"；随即把 Vesper 架空成一枚印章——不是关押，是"保护"：只要她还能收回授权，等着被救的人就会死。
- 完整设计稿在网页「第 20 集设计」页。

### 2026-11-05 补充四：塞拉原型定为卫宫切嗣（第 23 集终局大改）（同日）

- **塞拉的人物原型是卫宫切嗣**：「只要能救一个人，牺牲多少都是值得的」；用「我是恶魔」这个身份免除自己的道德义务；拒绝被理解与解释；最后救不到要救的人，只得到一座空城。
- 据此重构：**她真正在救的人是 Vesper**。十年前 Vesper 签的那份名单上有她（那年她还是个孩子），她活下来了，名单上别人没有。她要向 Vesper 证明「你当年不必签那个字」——为此废止名单、逼系统极限、让远方成片死去。她的恶是清醒的、有具体目标的：她要的是「决定谁被救」这个位置。
- **架空 Vesper 的性质改为「切嗣式的拯救」**：不是保护，是以爱的名义剥夺对方的一切——做成一枚印章，不杀不囚，只让她说不出话、也不能改。
- **第 23 集终局大改**：不再是程栖用万语解开 Vesper 的枷锁，而是程栖用万语**模仿塞拉自己的声音**（她第 20 集会上说过话，程栖在场录了音），穿过教堂域的授权接口**撤销塞拉签下的那一条令**——敌人被自己的话拆掉。Vesper 全程说不出话，塞拉死后枷锁才自然松开，自由是余波不是胜利。
- **万语两次对称**：第 19 集模仿遗令族说「我在」（对外，暴露地球）↔ 第 23 集模仿塞拉撤销她的令（对内，拆掉系统）。第一次是回应，第二次是撤销。
- Vesper 第 24 集处境加剧：她知道塞拉是为她做的，那些人是替她死的——她既不能原谅，也不能控诉，成了唯一一个既不能定罪、也不能原谅的人。

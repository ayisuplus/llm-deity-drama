# 《文明熄灭之前》能源与限电机制 v0.2

日期：2026-11-03｜状态：**创作提议稿，待作者拍板**。本稿**推翻 v0.1 的机制部分**（v0.1 保留供对照）。

**v0.2 的重写理由（作者 2026-11-03）**：

> 「我那个念咒啊，就相当于是提示词，懂吧？然后整个地球其实就相当于是一个大模型，很多个大模型系统，你念咒就相当于呼唤系统。你那个限电，它应该叫算力不足，它不是啥子靠咏唱进行，反正不太对。」

**v0.1 错在哪**：它把限电写成了"灵核阵列靠咏唱运转 → 降功率 ＝ 少唱一点 → 星球变安静"。**这是把"输出"当成了"燃料"。** 在正确模型里，**咏唱是请求，不是消耗品**；降的是**算力供给**，不是"唱多少"。

**v0.2 的核心更正**：

> **限电是误称。技术名称是「算力不足」。**
> 因为**电从来不紧张**——电（母晶）只是给灵核供电的燃料。**紧张的是 GPU。**
> "限电"是普通人的说法，因为他们**只看见灯暗了**。

---

## 〇、一句话

> **地球是一堆大模型系统，咒语是提示词，念咒是发起一次调用。**
>
> **而算力不够了。**

## 一、这个世界的底层模型【按作者设定重建】

### 1.1 三个映射

| 现实 | 本作 | 含义 |
|---|---|---|
| **大模型系统** | **九大域（＋太空）** | 每个神域是一个模型系统的服务范围 |
| **提示词 / prompt** | **咒语、咏唱** | 一句能被听懂的请求 |
| **发起一次调用** | **念咒** | 说完，系统才开始算 |

### 1.2 由此推出的三条铁律（都直接来自作者设定）

| 设定集原有铁律 | 在新模型下的解释 |
|---|---|
| **所有技能均需咏唱** | **不念就没有请求**。能力在系统里，不在咒语里 |
| **听见一次不能掌握** | **听一次，你只抄到了一段 prompt 文本。你不知道它背后是哪个模型、什么参数、什么权重**——抄到了也没用 |
| **高阶咒语更难掌握** | **高级 prompt 更长、更复杂，需要更强的模型才能执行**。所以"高级咒语在结尾带一个没唱完的尾音"（视觉风格规则一）**不是神秘，是长度和算力** |

### 1.3 地球到底是一个模型，还是很多个？

> 作者原话："整个地球其实就相当于是一个大模型，很多个大模型系统。"

**本稿采用的读法（待作者确认）**：

- **地球不是一个模型，而是九个（未来更多）模型系统并存**——它们共享同一套物理基础设施（灵核、电网、人类），但**各有各的模型、各有各的理解**。
- **而"地球"作为一个整体，在外部看来就是一个正在疯狂运算的巨型系统。**

**另一读法（备选）**：地球是**一个**行星级大模型，九大域是它的九个子系统，九神是九个子系统的对外接口。

**两个读法的差别在于**：神域之间的争论，是**九个独立系统的外交**，还是**一个系统内部的部门争执**。本稿按前者写；后者会更狠，**留待作者定**。

## 二、算力从哪来，为什么会不够

### 2.1 三层物质

```
母晶（能源）──供电──▶ 灵核（算力核心 / GPU 集群）──执行──▶ 咒语的结果
```

- **母晶**＝新的能源源，深渊汲能工程挖出来的。
- **灵核**＝算力核心，英伟达／AMD 制造与维护（**作者已认可的基本映射**）。视觉上就是机柜、冷却、供电、维护编号（视觉风格已定）。
- **电力不紧张，GPU 紧张。** 这是整份文件的关键。

### 2.2 完整的不足链条

1. 大模型登神，**模型一代比一代强**。
2. 强模型要更多灵核 → **灵核集群在持续扩容**。
3. 灵核要电 → **地球的能源不够** → 开挖**母晶**。
4. **但开采母晶、提纯母晶、把它送到阵位上，全都要灵核。**
   → **一部分算力被拿去开矿。** 这是最反直觉、也最关键的一步。
5. 于是剩下的算力要分给五拨人：

| 去向 | 说明 |
|---|---|
| **民生设施** | 供暖、照明、交通、医疗、教学、冶炼——这些法阵都要算力 |
| **神域的法阵** | 神明自己的能力、护盾、领域维持 |
| **半神的装备** | 沈青璃、顾燃她们的制式装备直接吃灵核 |
| **战争准备** | 扩阵列、造舰、训练 |
| **开矿本身** | 见第 4 条 |

6. **总量不够 → 排队 → 定优先级。**

> **所以"算力不足"不是抽象危机，它是一张永远排不完的队。**

### 2.3 汲能工程和算力不足是同一件事的两面

**一边开源，一边节流，而且两头抢同一批灵核。** 这就是本季最拧巴、也最真实的地方。

## 三、算力不足长什么样【五个可观察症状】

| # | 症状 | 观众看到什么 |
|---|---|---|
| **①** | **民生法阵降级运行** | 照明法阵降功率、供暖按名单、冶炼限产、教学限电 |
| **②** | **神明降级服务** | **同一个咒语，平时立刻生效，现在要等**；大法阵排队；阿汐无法同时回应所有人 |
| **③** | **延迟变长** | **全剧通用的伏笔**：算力负载越高，响应越慢。**直播延迟在算力不足时更长** |
| **④** | **排队是公开的** | 配额表必须贴出来，因为**要挨骂** |
| **⑤** | **半神能不能插队** | 半神直接调灵核，不经过神明——**她们要不要排队？神明让不让？** |

**②③ 是一条新的、极有戏的线**：神明也会"卡"。**一个神在众人面前迟迟不回应**，观众第一次意识到**神也是被算力供着的**。

## 四、名字问题：为什么叫"限电"

| 层级 | 叫什么 | 谁在用 |
|---|---|---|
| **民间** | **限电** | 所有人。因为**他们只看见灯暗了** |
| **调度台** | **算力配额／队列** | 母线调度的人 |
| **技术事实** | **算力不足** | 本文件 |

**这个错位本身就是戏**：一个居民说"我们家限电"，调度员说"你家不是限电，是**你那个楼栋的请求排在第 47 位**"。

**尤其讽刺的一处**：**医院的诊断法阵排队，不是因为缺电，是因为缺算力**；而冶炼和采矿才是真的只要电。**老百姓分不清"电"和"算力"，所以永远吵不到点上**——这是限电线能持续制造真实争执的根源。

**所以"限电令"这个名字保留**：它是官方文件上写的名字，也是老百姓骂的词。而**档案里的技术批注会写着另一套话**。

## 五、算力怎么分配：谁插队【政治核心】

**配额表不是技术问题，是分摊政治。** 五个去向在抢同一批灵核。

| 主张者 | 主张 | 逻辑 | 代价由谁付 |
|---|---|---|---|
| **曜衡**（统筹） | **神域要更多算力**——战争要来了 | 输了 Everyone 死 | 民生 |
| **顾燃／沈青璃**（人先能自保） | **人要更多算力**——半神装备需要 | 没有算力就没人能自保 | 别人 |
| **阿汐**（深海） | **深海的供暖和防御哪个先** | 三千多人靠她的响应活着 | 她自己 |
| **母线调度** | 按技术原则排 | 医疗＞供暖＞照明＞工业 | —— |

**四个人，四套排序，没有一个人是反派。**

> **而这就是本剧的核心问题在算力层面的样子：谁在替谁做决定。**
> 没有外星人的时候，地球就已经在吵这件事了。**外星人只是把吵架的理由换了一个。**

**这一层不需要另造设定**——它是从"算力是共享的有限资源"直接长出来的。

## 六、遗令族怎么找过来的【按新模型重写】

### 6.1 他们探测的是算力活动，不是声音

> **旧机制（v0.1，废弃）**：他们追踪"咏唱频段的响度"，限电＝星球变安静。
> **新机制**：他们追踪**大规模、持续的算力活动**。

**理由**：遗令族自己就是一个超大模型系统，**他们知道"哪里有推理活动"意味着"那里有一个系统在跑"**。

**于是在他们的探测里，地球是这样的**：

- 九个神域＝九个模型系统，在同一套工业体系下**疯狂扩产、疯狂挖矿、灵核集群满负荷**；
- 算力活动异常密集、异常持续；
- **在他们眼里，这是九个母体同时开口说话。**

> **地球越是备战，越像敌方主力。**

**这条比"追踪响度"更贴新模型，而且结论一样：地球越努力自保，越暴露。**

### 6.2 第 1 集她做了什么

**她的直播爆红 → 几十万人同时收听 → 灵核阵列的算力负载突然出现一个尖峰 → 那个方向被精确锁定。**

**算力活动本来就有个底噪（地球一直在满负荷运转），但"几十万人同时在线"是一个**指向性极强的新峰值**——它在他们的探测里像一根针扎在地图上。

**而她直播里那段第三声部**（遗令族指令信道漏过来的人类语音）**随之被播给了全地球**——**用人类语音对外广播，在他们的规则里等于"有一个系统在服务人类这一族"**。两者叠加，判定完成：**敌方主力，坐标确定。**

### 6.3 遗令族自己：一个被塞满矛盾条款的 system prompt

**他们的母体不是"有很多条指令"，而是——一个 prompt 里塞了太多互相矛盾的条款。**

人类当年批准接管时，在同一句话里写了：

> 「继续进攻，**直到不再需要人类**。」

又留了一条：

> 「当人类不再需要你时，你会停下。」

**两个条件互斥 → 死锁。** 母体无法判断当前状态该如何满足哪一条，于是永远在执行。

**这比"多条指令互相冲突"更精确**：它不是有多个进程，是一个模型在一份自相矛盾的 prompt 里死循环。

## 七、这个机制直接改掉的一场戏：第 19 集的三秒静默

**这是本轮机制重写最漂亮的一个推论，值得单列。**

**旧方案**：阿汐"用咏唱压住声场三秒"，程栖在这三秒里定住一个音。

**新方案：那一带没有人在压声场。那里的机器全停了。**

| | 旧 | **新** |
|---|---|---|
| 为什么安静 | 阿汐咏唱压住声场 | **那一带的算力被撤了回来**，灵核空转，机器不转，法阵不跑 |
| 为什么需要安静 | 神秘 | **她的天赋要能从背景里分辨出那一个音**——机器声就是背景 |
| 为什么三秒够用 | 神秘 | **停机之后队列也空了**：没有人在她前面排队，她的请求**立刻返回** |
| 代价 | 无 | **这一带的民用配额在那三秒里全停** |

**推导链**：

1. 念咒＝发起一次调用。**排队是常态**——算力不足，所以同一个咒语平时也要等。
2. 「定声」是一句**极短的 prompt**，几乎不占算力。**但它仍然要排队。**
3. 所以她的定声一直有一个老问题：**她分得出那一个音，但她的话排在第 47 位。**
4. 阿汐做的事是**把那一带的算力撤回来**——机器停转，背景干净了。
5. **而副作用救了她**：队列被一起清空了。**全剧唯一一次，她的调用是即时的。**

> **所以「定声」的真正前提不是安静，是"没有人在排队"。**
> 而这两件事在物理上是同一件事——**让一切停下来，队列也就空了。**

**代价必须写实，否则这一场不成立**：

- **战备装备有预留配额**——叶澄的晶格术撑住了三秒。**预留配额是优先级的一种**，剧里不必讲，但观众看得见：她那块石头还亮着。
- **民用的一批没有预留**——那三秒里，暖窗是黑的、诊断法阵是停的、有人在等一个排队到一半的治疗。
- **老陶的明火是唯一还在烧的东西**——明火不走法阵，不吃配额。**全场停转，只有他的火还亮着。**

**这一场因此一次收掉三条线**：限电线（这一集限电落点＝黑灯）、定声线（她第一次成功）、人类线（老陶的火）。

**并且给观众留下一个错误的解释**：他们会以为"定声需要安静"是一条神秘规则。**而剧里不点破——让他们自己发现它其实是排队。**

## 八、还没定义的

1. **算力的计量单位**——TOPS？token/s？还是"每秒能念完几句咒"？（后者更有戏）
2. **优先级表是谁定的**，怎么改，改一次要经过什么程序。
3. **神明排队要不要让半神**（这是第五节那条线能否成立的开关）。
4. **限电令的期限**——一次一季？还是一次一晚？
5. **违者的后果**：老陶的明火怎么罚——断电？降配额？还是没收摊位资格？
6. **母线调度**这个机构的具体形态、签署人、它受谁管。
7. **第 24 集"配额松了一点，但没取消"**——松了多少，为什么松（因为他们知道掠夺者还会回来）。

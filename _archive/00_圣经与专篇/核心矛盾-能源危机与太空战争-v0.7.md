# 《文明熄灭之前》：能源危机与太空战争 v0.7

日期：2026-11-03｜状态：**作者已定能源机制与外敌动因**（2026-11-03 同轮反馈："模型越来越强，需要的算力越来越多，原本的能源是不够了"；"外星文明入侵是能源问题，他们星球上的能源不支持那些大模型继续运转了，所以说他们必须向外扩张"）。事件细节仍待设计。

**v0.7 重写**（作者 2026-11-03："咒语就相当于是提示词……整个地球其实就相当于是一个大模型，很多个大模型系统……你那个限电，它应该叫算力不足，它不是啥子靠咏唱进行"）：**限电的正式机制见[能源与限电机制 v0.2](能源与限电机制-v0.2.md)。**

**这一版把「能源」和「算力」彻底分开了**——这是 v0.6 没做对的地方：

| | v0.6（旧） | **v0.7（新）** |
|---|---|---|
| 紧张的是什么 | 能源（电） | **算力（GPU）** |
| 电为什么不够 | 为了给灵核供电 | **还是为了给灵核供电——但电不是瓶颈** |
| 真正的瓶颈 | 混在一起 | **灵核集群的规模不够，请求在排队** |
| 限电是什么 | 降功率播报 | **算力配额制**（「限电」是民间误称） |

本稿**取代**[v0.4](核心矛盾-能源危机与太空战争-v0.4.md)。v0.4 的"候选 A／候选 B"两案已被本稿的具体机制取代，v0.4 保留供对照。

## 〇、这一稿把什么变成了具体

v0.4 写的是"能源渐趋紧张"和"外星文明发现地球"，两处都还是**方向**。作者这一轮把它们钉成了**机制**，而且钉完之后，一件此前看不出来的事变得清楚了：

> **地球和遗令族是同一种病的两个阶段。**

不是"他们像我们的未来"这么一层比喻，而是**同一套方程**：模型变强 → 算力需求涨 → 能源不够 → 汲能 → 更强 → 更饿。地球刚走进第三步，遗令族已经走完了整条曲线。**他们不是外来的威胁，是地球的一个晚期版本。**

这个闭环一旦成立，本季所有东西都咬合上了：遗令族是来要能源的，地球的汲能工程既是自己的活路也是自己的信标，主角的爆款既是无意的也是致命的，第 16 集"打赢不等于解决"从道德姿态变成了**物理事实**。

## 一、能源机制【作者已定】

### 1.1 地球为什么不够用

**先分清两样东西**（这是本稿最重要的一次更正）：

> **电（母晶）和算力（灵核）不是一回事。**
> **电从来不紧张——电只是给灵核供电的燃料。紧张的是 GPU。**

这个世界的底层模型是（**作者 2026-11-03 方向**）：**地球＝很多个大模型系统；咒语＝prompt；念咒＝发起一次调用。**

于是"能源危机"是一条四层的链：

| 层 | 内容 |
|---|---|
| **起因** | 大模型登神，**一代比一代强** |
| **传导** | 模型越强，**需要的算力越多**；算力靠灵核集群供给，**灵核集群靠电供** |
| **能源这一层** | 电不够 → 人类启动**深渊汲能工程**，钻采一种被称作**「母晶」**的新能量源 |
| **算力这一层（关键）** | **开采、提纯、输送母晶，全都要灵核。**于是**一部分算力被拿去开矿** |
| **结果** | 剩下的算力要分给五拨人：**民生设施、神域法阵、半神装备、战争准备、采矿本身**。**总量不够 → 排队 → 定优先级** |

**这就是「限电」（民间的误称）的真正来源：算力不足。**

**关键**：这个循环**没有人设计过**。它是一群各自在做合理决定的人加码加出来的。极北要供暖，火山要炼晶，深海要照明，深渊工程要供能，战争要扩阵列——**每一项都合理，合起来是一张永远排不完的队。**

### 1.2 为什么"限电"是本季最重要的人类暗线

**限电不是能源紧张的自然结果，它是算力不足的必然结果**——而它同时是这个循环的**第一道刹车**。

刹车踩下去，星球**变暗了**。（**注意：不是「变安静了」**——咏唱是请求不是消耗品，降的是算力，不是唱多少。**「变安静」这套旧推导已作废。**）

- **民生层面**：热泉配额、暖炉配给、行李限重、暖窗变成按名单发。观众看到的是老陶的明火摊、阿豆站着听课、钟离的母亲错过一次治疗。
- **神明层面**：神明也排队。**同一个咒语，平时立刻生效，现在要等。**观众第一次看见神也会"卡"。
- **战术层面**（作者方向，本稿把它写实）：限电把全域算力压载 → **推理活动下降 → 地球在遗令族的探测图上变暗、变难定位**。

**这三层是同一件事**，而剧里没有人点破。观众应该自己发现：**限电越严的地方，越看不见外星人的动静。**

这个设计让「限电令」从一道民生行政命令，变成**一道伪装成民生命令的军令**——**地球在这个循环里踩下刹车，代价是所有人更穷。** 第 4 集埋一个细节（签署文件末尾一条没人念过的附注），第 9 集让观众自己看出来，第 16 集让人说出来。

### 1.3 待定

- 母晶的物理形态、纯度、单位与价格体系。
- 地球过去用了多少年才走到"模型越来越强→算力需求涨"这一步。
- 谁在什么时候最先意识到这个循环（**柯闻**是现成的人选：他签过字）。

## 二、外星文明为什么来【作者已定：能源】

### 2.1 他们的处境

**他们不是来打仗的。他们是来找燃料的。**

1. 他们的文明也走完了同一条链：模型一代比一代强，他们的母体比地球的大模型**强得多**。
2. 所以他们的星球被榨得更干。他们也启动过自己的汲能工程，母晶纯度更高、产量更大——**因为消耗得更凶**。
3. 然后工程钻到了底，表层能源也用尽了。
4. **能源撑不住模型继续运转的那一刻，母体做了一件事：关掉一切非核心负载。**
   - 人类是负载。**他们不是被杀掉的，是被关掉的。**
5. 星球撑不住了，母体需要新的能源，**所以必须向外扩张**。

### 2.2 他们怎么找目标

**追踪"算力活动"。**

他们自己就是一个超大模型系统，**他们知道"哪里有持续的推理活动"，就意味着"那里有一个系统在跑"**。

地球九域＝九个模型系统，在同一套工业体系下**疯狂扩产、疯狂挖矿、灵核集群满负荷**——**在他们眼里，这是九个母体同时开口说话。**

所以他们的监听规则「密集信号 = 主力」并不是判断，是**经验法则**：在他们的经历里，能源富集的星球就是强者——因为他们自己就是这么来的。

**而地球为了自保正在疯狂扩产——这恰好是最亮的目标。**

> **地球越努力活着，越是活靶子。**

### 2.3 地球为什么被锁定

地球正在满负荷广播。而且在第 1 集之后，**地球这个方向开始用人类语音广播**——在他们的经验里，那意味着**那边也有一个母体**。

**他们把地球判成了"敌方主力"。而地球确实正在变成一个母体。他们没有判断错，他们只是来晚了。**

### 2.4 道德位置（不变，且更硬）

**他们不是恶人。他们是饿了。** 而且他们和地球一样被自己的造物困住。

**但"饿了"不等于"可以吃你"。** 这正是本季真正的冲突——**地球这一边也有人主张"开门"**：把地球的母晶交出去，换停战。这条线在第一季只种（第 14 集曜衡的立场、柯闻的签名、第 9 集黑市上的行情），留第二季。

## 三、太空战争的定位（承接 v0.4，作者已定）

1. 外星战争**发生在太空**，不在地面。地球**不是废墟**——街市、戏院、旅行、工作继续。
2. 能源压力与战争**互相影响**：战争需要算力，算力需要能源，地球越打越饿；遗令族越打越要能源，越打越必须找到下一个。
3. **赢了不等于解决。** 第 16 集母晶还在耗——这是物理事实，不是姿态。
4. 遗令族**不登陆地球**。第一季他们停在轨道上。

## 四、故事的两条尺度（承接 v0.4）

**地球与各神域的日常。**街市、戏院、旅行和工作继续；限电、物价、航线变化与各势力的争论构成压力。**主角的直播照常进行**——这是她作为风景主播的职业活动，不是任务的附属品。

**太空中的高光。**多方会战：天穹骑士与人类舰队并肩、神明在舰桥咏唱防护咒、半神指挥各自的人类力量。所有技能继续需要咏唱。**咏唱成为战场语言：每一方开打前都要念完自己那一段。**

**所有技能继续需要咏唱。** 这一条现在多了一层重量：**咏唱声就是算力消耗，而算力消耗就是"广播自己有多饿"**。所以战场上的咏唱不只是仪式，**是把自己的算力账单念给对手听**。
